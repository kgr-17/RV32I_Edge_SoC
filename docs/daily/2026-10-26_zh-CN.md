# T009 第一次验收失败及修复

RTL 综合检查通过，但存储器测试在种子20261025、数据端口、7周期延迟的最终排空检查失败。已检查的每个边沿都与独立记账器相符；问题是测试停止产生随机请求后，只给了一笔事务的完成时间，而此时可能还有一笔已接收事务和一笔已经提出、必须继续保持的请求。现按两笔固定延迟事务加握手间隔计算排空上限，改为2×延迟+3个边沿。保留最终必须没有未完成事务的断言，也没有减少种子、覆盖项或稳定性检查。

另外，我写入检查注册表时使用了 Windows 默认换行，Git 空白检查正确拒绝了 CRLF。现恢复 LF，注册表内容和检查规则均不变。第一次模型、测试和注册表的原始字节已存入项目内 ZIP 并校验哈希；失败记录、成功的11组轨迹及错误诊断都保留。接下来使用第二次正式验收机会，重新运行全部必需检查。这个修复体现的是测试环境也需要验证，不能把未完成测试误报为通过。
