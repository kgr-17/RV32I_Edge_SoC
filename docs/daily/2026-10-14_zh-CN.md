## 2. 为什么先做这些

长周期硬件项目不能依赖聊天记录记住进度。Persistent State（持久状态）告诉下一次会话当前任务、当天名额和验证尝试次数；Verification Gate（验证门禁）阻止“测试没有运行却声称成功”。先建立这些机制，可以减少后续 CPU 开发中的状态丢失、重复劳动和错误结论。

## 3. 在 CPU / FPGA / ASIC 系统中的作用

现在验证的是工程流程，不是 CPU 电路。将来 RTL 单元测试、指令比较、Pipeline Hazard 测试、Vivado timing report 与 ASIC PPA 都需要纳入同一套证据链，但这些证据互相不能替代。Simulation PASS 不能证明 FPGA Timing Closure，更不能证明实体硬件或 ASIC signoff。
