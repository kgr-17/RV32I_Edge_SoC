# Weekly owner/Codex review prompt

Do a READ-ONLY audit of current RTL and DV progress. Compare requirements in `docs/ARCH_SPEC.md`, requirements-to-tests traceability, evidence, recent commits and milestone tasks. Identify false-green testing risks, missing edge cases, unmeasured PPA claims, and overgrown scope. Propose at most three backlog improvements but DO NOT change requirements, modify source, mark a task done, or approve a gate. Summarize which concepts the human project owner must be able to explain in a technical interview.
